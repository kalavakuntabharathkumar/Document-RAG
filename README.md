# Document Q&A System (TF-IDF RAG)

A small, reproducible retrieval-augmented question-answering application using Python, scikit-learn TF-IDF, cosine similarity, pypdf, OpenAI API, and Streamlit.

## What it does
- Reads PDF files from `data/pdfs/` (six educational reference PDFs are included).
- Extracts text and splits it into word-based chunks.
- Ranks chunks with TF-IDF cosine similarity and returns the top three.
- Sends only retrieved passages to the LLM and asks it to abstain when evidence is insufficient.
- Shows source file and chunk references.
- Includes a 20-question retrieval evaluation comparing 200-word and 500-word chunks.

> The included PDFs are locally authored educational reference notes, not original WHO publications. Replace them with public-domain/publicly accessible PDFs if you want to use WHO source documents. Evaluation scores are generated by the included script against this bundled corpus; they are not a claim of external clinical validation.

## Setup
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```

## Run
```bash
streamlit run app.py
```
Set `OPENAI_API_KEY` in your environment to enable generated answers. Without it, the app still retrieves passages and displays a clear setup message.

Windows PowerShell:
```powershell
$env:OPENAI_API_KEY="your-key"
streamlit run app.py
```

## Evaluate retrieval
```bash
python -m src.evaluate
```
The script prints the number of questions for which a relevant expected document appears in the top three for each chunk size. Retrieval depends on the bundled corpus and may differ if you replace the PDFs.

## Project structure
- `data/pdfs/`: six included PDF reference notes
- `src/ingest.py`: PDF extraction and chunking
- `src/retrieval.py`: TF-IDF retrieval
- `src/qa.py`: grounded LLM answer generation
- `src/evaluate.py`: 20-question chunk-size comparison
- `app.py`: Streamlit interface
